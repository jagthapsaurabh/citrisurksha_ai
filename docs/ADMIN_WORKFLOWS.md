# Admin Workflows

## Pest catalogue management

Admin can create or update:

- pest ID/slug
- common/scientific name
- symptoms
- lifecycle details
- prevention
- cure/control
- organic control
- chemical control
- safety note
- reference image URL

## Training data management

Admin can:

- upload labelled pest images
- label lifecycle stage
- mark images verified/unverified
- review farmer detections
- relabel incorrect AI predictions
- approve high-quality farmer images for training

## AI model management

Admin can:

- create dataset version
- queue training
- view training jobs
- compare model metrics
- promote model to active version
- rollback model if field performance drops

## Blog/calendar management

Admin can publish farmer advisory content and month-wise citrus calendar tasks.
